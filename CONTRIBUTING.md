# Contributing to LumaPass

Thank you for helping make LumaPass clearer, more inclusive, and safer.

- Open an issue before a substantial feature or API design change.
- Keep the application within legitimate, non-payment Apple Wallet passes.
- Never add payment cards, real users' private data, Wallet credentials, issuer secrets, signed pass files, app-store artwork, third-party brands, or unlicensed uploads.
- Run `python -m pytest`, `ruff check backend`, and `ruff format --check backend`; on a Mac, regenerate XcodeGen and run the iOS simulator tests.
- Explain the visible behavior, accessibility implications, data migrations, and test results in pull requests.
- Unless explicitly agreed otherwise, contributions to code are offered under the repository's Apache-2.0 license.
- A user's community artwork continues to be governed by the license declared for that artwork; it is not relicensed as source code by a pull request.
